# Selenium Login Test (TestNG)

This project is a basic automation test written in Java using Selenium WebDriver and TestNG.  
It covers a simple login functionality for practice purposes.

## Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Eclipse IDE

## Project Structure
- `src/test/java/tests/LoginTest.java`: Main test class
- `pom.xml`: Maven dependencies

## Test Scenario
1. Open browser and navigate to [Practice Login Page](https://practicetestautomation.com/practice-test-login/)
2. Enter valid credentials
3. Click login button
4. Verify successful login
